# Участие в разработке

Основной целевой вариант — Samsung Tizen 5.5 / Chromium 69. Для работы с
исходниками нужны Node.js 22+ и npm. Скрипты подписи и установки рассчитаны
на Windows; установленные приложения проверяются на физическом ТВ.

```powershell
npm.cmd ci
npm.cmd run test:run
npm.cmd run build
git diff --check
```

Перед изменением чувствительных к производительности путей прочитайте
[AGENTS.md](AGENTS.md) и [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
Сохраняйте кеши, данные каталога и существующий конвейер постеров.

Полный ESLint и stylelint содержат прежние замечания исходного клиента;
их состояние записано в [TIZEN_VALIDATION.md](docs/TIZEN_VALIDATION.md).
Новые файлы должны проходить соответствующий lint. Проход тестов не
подтверждает длительную стабильность или поддержку всех кодеков на ТВ.

## Техническая диагностика

В обычной сборке отправка диагностики отключена. Для временного тестирования
на своём ТВ задайте его IP в `KINOWATCH_TV_ADDRESS`, запустите
`node scripts/tv-diagnostics.mjs` и соберите с `KINOWATCH_DIAGNOSTICS_URL`,
указывающим на `/event` вашего компьютера, порт 8767.

Сервер принимает только разрешённые технические поля от указанного ТВ и
localhost. Ссылки на фильмы, названия и токены передавать нельзя. Логи
сохраняются в игнорируемом `artifacts`. Перед публичным выпуском диагностика
обязательно отключается; `release:prepare` делает это на время своей сборки.

## Изменения и проверка

В pull request опишите поведение до/после и фактически выполненные проверки.
Укажите модель ТВ для физических тестов. Не включайте сертификаты, токены,
логи или персональные сетевые адреса. Сохраняйте MIT и уведомления исходных
авторов; новый код из проектов с другой лицензией требует отдельной оценки.
