# KinoWatch 0.2.2 — Samsung Tizen preview

Первый экспериментальный выпуск Samsung Tizen порта KPuppy.

Включает каталог KinoPub, вход по коду, фильмы и сериалы, поиск, закладки,
историю и управление обычным пультом Samsung. Для воспроизведения используется
Samsung AVPlay; основной проверенный вариант — AVC/H.264 через HLS4.

## Проверено

Samsung UE43TU7090UXRU (2020), Tizen 5.5: установка, запуск, вход, каталог,
видео 720p со звуком AAC-LC и продолжение с сохранённого места.
Пользователь также подтвердил 1080p, 4K (2160p), звук и переключение
аудиодорожек на этой модели.
683 автоматических теста прошли. Другие модели, все аудиокодеки и
субтитры, Live TV и длительный просмотр ещё не подтверждены на физическом ТВ.

## Установка

Скачайте `KinoWatch-0.2.2-build.zip`, распакуйте, создайте свой Samsung TV
профиль с DUID вашего телевизора и подпишите сборку. В архиве находятся
пошаговая инструкция `docs/INSTALL.md` и скрипты Windows. Node.js для этого
варианта установки не нужен. Для сборки из исходников нужен Node.js 22+.

Компьютер требуется для установки; затем приложение работает на телевизоре.
Для просмотра нужен собственный аккаунт сервиса.

## Ограничения

Рекомендуемые настройки отключают HEVC/HDR для клиента в сервисе.
720p, 1080p и 4K подтверждены на указанной модели; все варианты файлов
ещё не проверены. MP4 на проверенном ТВ
давал ошибки декодирования. Автоматические повторы при обрыве реализованы,
но не считаются подтверждением длительной стабильности.

Подписывать обновления нужно тем же author certificate. Архив релиза
не содержит сертификатов владельца и готовой универсальной подписи для всех ТВ.
