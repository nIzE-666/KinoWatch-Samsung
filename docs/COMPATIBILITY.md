# Совместимость KinoWatch 0.2.2

Статус: экспериментальный Samsung Tizen порт. Проверки на одном телевизоре
не являются подтверждением работы всех файлов и моделей.

## Проверенное устройство

Samsung **UE43TU7090UXRU**, модель 2020 года, группа 20TV_BASIC1,
Tizen 5.5 / Chromium 69. Сборка требует Tizen 5.5 и новее; это нижняя граница
в конфигурации приложения, а не перечень проверенных моделей.

| Возможность | Результат |
| --- | --- |
| Установка и запуск подписанного `.wgt` | Подтверждены через SDK |
| Вход по коду, каталог | Подтверждены пользователем |
| 720p, AVC HLS4 через AVPlay | Подтверждены картинка и звук |
| Продолжение с 138 секунд | Подтверждено пользователем и callback AVPlay |
| Звук в проверенном потоке 720p | AAC-LC; озвучки с другими кодеками не проверены |
| 1080p | Воспроизведение подтверждено пользователем 2026-10-12 |
| 2160p / 4K | Воспроизведение подтверждено пользователем 2026-10-12 |
| Звук и переключение аудиодорожек | Подтверждены пользователем; все аудиокодеки не проверены |
| HEVC / HDR | Отключены в рекомендуемых настройках клиента |
| Встроенные и внешние субтитры | Реализованы; варианты не проверены на ТВ |
| Автопереход к следующей серии, Live TV | Не проверены на ТВ |
| Длительный просмотр и восстановление после обрыва | Не подтверждены на ТВ |
| Другие модели Samsung | Не проверены |

## Почему выбран HLS4 / AVC

На этапе разработки предоставленный HEVC HLS доходил до 99% буферизации,
но не завершал prepare. MP4 через AVPlay сначала запустился, затем оборвался
и зависал при восстановлении позиции. MP4 в браузерном плеере завершался
MEDIA_ERR_DECODE (3), в том числе после отключения запроса HEVC.

Рабочий поток HLS4 объявлял `avc1.640028,mp4a.40.2` — H.264 / AVC и AAC-LC.
Prepare занял около 12.2 секунды, восстановление позиции — около 4.8 секунды.
Причина MP4-сбоя окончательно не установлена; кодек MP4 не определялся по
манифесту другого HLS-потока.

Настройки сервиса для Samsung: `supportHevc=0`, `supportHdr=0`, HLS4 при
наличии опции; выбранный сервер сохраняется, `support4k=1` разрешает 4K.
Пользователь подтвердил воспроизведение 4K на этой модели. Кодек, битрейт и
частота кадров этого 4K-потока отдельно не зафиксированы; проверка одного
потока не подтверждает совместимость всех 4K-файлов.

## Ограничения платформы

В браузерном MSE-плеере Samsung 2020 года UHD не поддерживается; основной
AVPlay путь выбран отдельно. DTS не поддерживается Samsung TV 2020 года.
[Спецификация Samsung](https://developer.samsung.com/smarttv/develop/specifications/media-specifications/2020-tv-video-specifications.html).

Сетевые ошибки могут зависеть от сервиса, CDN и подключения ТВ. Подготовка
ограничена 45 секундами без прогресса и 120 секундами в целом; смена источника
не доказывает устранение причины сбоя.
