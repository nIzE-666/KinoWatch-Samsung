# Использование KinoWatch

## Первый вход

1. Запустите KinoWatch из Apps на телевизоре.
2. Откройте на телефоне или компьютере адрес активации, который показывает
   приложение. Используйте именно адрес с экрана: сервис может менять его.
3. Войдите в собственный аккаунт сервиса и подтвердите показанный код.
4. Дождитесь открытия каталога. Если код истёк, запросите новый на экране входа.

Пароль аккаунта не вводится в телевизионное приложение. Сессия сохраняется
локально на телевизоре. Для просмотра нужен доступ аккаунта к выбранному
контенту и работающий интернет на ТВ.

## Каталог и просмотр

Стрелками перемещайтесь между карточками и разделами, OK открывает выбранное.
«Назад» возвращает на предыдущий экран. Доступны поиск, фильмы, сериалы,
сезоны, подборки, закладки и история из исходного клиента.

В карточке выберите «Смотреть» или «Продолжить». Позиция хранится локально
и передаётся сервису. При продолжении плеер сначала запускает поток, затем
переходит на сохранённое время. Загрузка и перемотка могут занять несколько
секунд; на проверенном видео запуск с восстановлением занял около 17 секунд.

## Кнопки в плеере

| Кнопка | Действие |
| --- | --- |
| OK / Play-Pause | Пауза или продолжение; при ошибке — повтор |
| ← / → | Перемотка на 10 секунд, когда панель скрыта |
| ↑ | Показать управление |
| ↓ | Скрыть управление |
| ← / → при видимой панели | Выбрать кнопку; OK открывает её |
| 1 / красная | Качество |
| 2 / зелёная | Озвучка |
| 3 / жёлтая | Субтитры |
| 4 / синяя | Серии, если доступны |
| «Назад» | Закрыть панель; повторное нажатие выходит из плеера |

В списке качества перемещайте выделение стрелками и нажмите OK для применения.
Изменение качества может повторно загрузить поток. Список озвучки и субтитров
зависит от того, что возвращает сервис и что поддерживает телевизор.
Пользователь подтвердил звук и переключение аудиодорожек на Samsung UE43TU7090UXRU.

## Рекомендуемые настройки Samsung

Основной проверенный вариант:

- плеер: **нативный** — Samsung AVPlay;
- поток: **HLS4**;
- HEVC: выключен;
- HDR: выключен;
- для первой проверки качества: **720p**.

При первом применении этих настроек приложение сообщает сервису возможности
своего клиента. Настройки изображения самого телевизора не меняются.
В настройках приложения можно повторно применить рекомендуемые параметры.
Выбранное разрешение запрашивается при наличии подходящего файла; поддержка
720p, 1080p и 4K подтверждены пользователем на Samsung UE43TU7090UXRU.

Браузерный плеер доступен как запасной вариант. Его работоспособность для
всех файлов не подтверждена; на проверенном ТВ MP4 выдавал Decode 3.

## Ошибки и повтор

При ошибке нажмите OK для повтора или «Назад» для выхода. При обрыве
соединения во время просмотра предусмотрены до двух автоматических повторов
с обновлением ссылки и сохранённой позицией. Это не гарантирует доступность
сервера и совместимость файла.

Если ошибка воспроизводится, сообщите модель ТВ, версию KinoWatch, выбранное
качество, текст ошибки и шаги. Перечень проверенных возможностей и известных
проблем находится в [COMPATIBILITY.md](COMPATIBILITY.md).
